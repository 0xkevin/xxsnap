# Windows 开发规约

## 编辑工具跨场景一致性

1. 任何截图标注或编辑工具的新增、修改和缺陷修复，都必须同时审查并同步到区域截图、教笔、贴图编辑、滚动截图编辑及其他复用编辑工具条的 Windows 场景，不得只修改其中一处。
2. 同步范围包括主工具条、二级工具条、鼠标图样、选项状态、快捷键、绘制、选中、再编辑、撤销、删除及导出结果。
3. 应优先修改共享的编辑控制器、输入路由、工具条布局或渲染链路，避免为单个 `OverlayMode` 复制同一规则。
4. 如果某项行为确因场景差异不适用，必须在代码或测试中明确记录原因，不得静默遗漏。
5. 验证至少覆盖普通截图与教笔；涉及编辑页时，还必须覆盖贴图编辑与滚动截图编辑。
