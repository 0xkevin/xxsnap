# XxSnap 免费阶段后台失联兜底 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让当前免费阶段客户端无论后台、网络、缓存或系统时间是否异常都保持全部功能可用，同时为未来付费阶段保留严格的授权兜底逻辑。

**Architecture:** 在构建产物中写入不可由后台改变的 `XXCommercialReleasePhase`。商业权限控制器先依据构建阶段决定访问基线：`free` 永久返回 `allFree`，后台刷新仅用于缓存合法的免费策略和记录诊断；`paid` 完整保留现有授权、宽限期和离线逻辑。Release 构建脚本校验阶段值与启动策略匹配，避免误发。

**Tech Stack:** Swift、AppKit、XCTest、Xcode build settings、Info.plist、Shell 构建校验
