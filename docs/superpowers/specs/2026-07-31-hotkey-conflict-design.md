# XxSnap 快捷键录制与冲突处理设计

**日期：** 2026-07-31
**状态：** 已获用户确认，待实现

## 目标

扩展设置页快捷键录制能力，使用户可以直接设置 `F1`–`F12`，并统一处理 XxSnap 可配置快捷键与编辑工具条固定快捷键之间的冲突。

实现必须满足：

- `F1`–`F12` 可不带修饰键直接设置。
- 普通字母、数字和符号仍须包含 `Command`、`Option`、`Control` 或 `Shift`，避免全局截获正常输入。
- 可配置快捷键之间发生冲突时，允许用户确认后覆盖。
- 被覆盖的可配置动作自动清空快捷键。
- 不可配置的工具条快捷键禁止被设置页快捷键覆盖。
- “贴图”工具条快捷键与设置页“恢复最近隐藏的贴图”共用同一份动态配置。
- 所有新增提示同时提供中文和英文。

## 当前问题

`ShortcutRecorderButton` 已经能够把 `F1`–`F12` 转换为 `HotKeySettings`，`HotKeyFormatter` 也能正确显示这些按键。但 `CaptureHotKeyController.apply` 统一要求快捷键包含修饰键，因此单独录制功能键最终会返回 `missingModifier`。

当前重复快捷键只返回通用 `duplicate` 错误，没有携带冲突动作；它既不能让用户确认覆盖，也不能区分可覆盖的设置项和不可覆盖的固定工具条快捷键。

工具条“贴图”目前静态写为 `Command+1`。设置页修改“恢复最近隐藏的贴图”后，工具条按键匹配和括号提示不会同步变化。

## 方案选择

采用统一快捷键冲突注册表：

- `CaptureHotKeyController` 负责可配置动作的占用关系、覆盖事务和持久化。
- 工具条快捷键目录提供不可配置快捷键及其本地化名称。
- “贴图”从固定工具条目录排除，改为读取“恢复最近隐藏的贴图”的当前配置。

未采用的方案：

1. 仅在设置界面判断冲突：改动较少，但控制器其他调用入口可以绕过规则，持久化数据也可能形成重复占用。
2. 将所有工具条快捷键开放配置：能够统一处理，但明显扩大本次需求范围，也会增加设置页复杂度。

## 快捷键有效性

设置页接受以下快捷键：

1. 含至少一个受支持修饰键的普通按键组合。
2. 不带修饰键的 `F1`–`F12`。

不带修饰键的普通字母、数字和符号继续被拒绝。`Shift` 仍然视为有效修饰键，但冲突检测必须采用与工具条实际匹配相同的规则。例如工具条的普通 `S` 也会响应 `Shift+S`，因此 `Shift+S` 必须判定为与“矩形”冲突。

`Esc` 不可用于设置页动作，因为它是工具条固定的取消或完成编辑快捷键。

## 固定工具条快捷键

以下快捷键不可在设置页覆盖：

| 工具条动作 | 快捷键 |
| --- | --- |
| 矩形 / Rectangle | `S`，以及工具条实际会匹配的 `Shift+S` |
| 箭头线 / Arrow Line | `A`，以及 `Shift+A` |
| 画笔 / Pen | `B`，以及 `Shift+B` |
| 记号笔 / Marker | `H`，以及 `Shift+H` |
| 取色器 / Eyedropper | `P`，以及 `Shift+P` |
| 马赛克 / Mosaic | `M`，以及 `Shift+M` |
| 文字 / Text | `T`，以及 `Shift+T` |
| 序号 / Number | `N`，以及 `Shift+N` |
| 放大镜 / Magnifier | `G`，以及 `Shift+G` |
| 橡皮擦 / Eraser | `E`，以及 `Shift+E` |
| 滚动截图 / Scrolling Capture | `R`，以及 `Shift+R` |
| 撤销 / Undo | `Command+Z` |
| 重做 / Redo | `Command+Shift+Z` |
| 取消或完成编辑 / Cancel or Finish Editing | `Esc` |
| 保存 / Save | `Command+S` |
| 复制 / Copy | `Command+C` |

“贴图 / Pin”不在固定表中。它始终跟随可配置动作“恢复最近隐藏的贴图”的当前快捷键。

当录制结果与固定快捷键冲突时：

- 不修改当前动作或任何其他动作。
- 不尝试注册或保存。
- 中文提示：`与“<动作名>”快捷键冲突，禁止覆盖，请重新设置！`
- 英文提示：`This shortcut conflicts with “<action>”. It cannot be overridden. Choose another shortcut.`

## 可配置快捷键覆盖流程

可配置动作包括：

- 截图
- 全屏截图
- 识别文字
- 教笔
- 恢复最近隐藏的贴图

录制结果与另一个已启用的可配置动作冲突时，设置页弹出确认提示：

- 中文：`该快捷键已用于“<动作名>”，是否覆盖？覆盖后“<动作名>”的快捷键将被清空。`
- 英文：`This shortcut is used by “<action>”. Replace it? The shortcut for “<action>” will be cleared.`

用户选择取消：

- 保持两个动作的配置和注册状态不变。

用户确认覆盖：

1. 注销目标动作和被覆盖动作的旧注册。
2. 将新快捷键分配给目标动作并启用目标动作。
3. 将被覆盖动作加入禁用集合，使设置页显示为空。
4. 一次性持久化双方状态。
5. 注册成功后刷新菜单、设置页和后续新建的编辑工具条。

如果注册或保存失败，完整恢复两个动作此前的配置、启用状态、错误状态和注册状态，不允许留下半完成覆盖。

已禁用动作的历史快捷键不占用组合；用户可以直接将该组合分配给其他动作。

## 动态“贴图”快捷键

设置页“恢复最近隐藏的贴图”是工具条“贴图”的快捷键来源：

- 配置为 `F1` 时，编辑工具条按 `F1` 执行贴图，提示显示 `贴图 (F1)`。
- 配置为其他组合时，工具条匹配和提示同步使用该组合。
- 被另一个可配置动作覆盖或手动清空后，工具条“贴图”仍可点击，但不响应快捷键，提示中不显示括号快捷键。

捕获过程中设置页快捷键录制本来就被禁用，因此每次创建编辑浮层时从持久化设置读取一次动态贴图快捷键即可；不需要在浮层存活期间进行热更新。

菜单栏“恢复最近隐藏的贴图”继续使用同一配置。捕获期间该全局注册按现有逻辑暂时注销，避免与编辑工具条同时响应。

## 组件边界

### `HotKeyFormatter`

- 提供统一的快捷键有效性判断。
- 支持 `F1`–`F12` 的无修饰键显示、录制和菜单反馈。
- 提供从 `HotKeySettings` 到工具条匹配描述的转换，避免 Carbon 与 AppKit 两套按键规则漂移。

### `SelectionToolbarState`

- 保留工具条快捷键的单一定义来源。
- 对外提供固定快捷键冲突查询，返回冲突动作标识和本地化显示所需信息。
- “贴图”快捷键不再来自静态固定映射，而由当前浮层配置提供。

### `CaptureHotKeyController`

- 返回结构化冲突结果，而不是只有无上下文的 `duplicate`。
- 提供确认后的覆盖操作，并保证注册及持久化回滚是原子的。
- 启动恢复时继续处理旧版本可能存在的重复设置，不能因本次改动破坏兼容性。

### `PreferencesWindowController`

- 根据结构化冲突显示固定冲突错误或可配置冲突确认框。
- 用户确认后调用覆盖操作；取消时只刷新录制控件显示。
- 所有动作名称和提示根据当前语言显示。

### `CaptureCoordinator` 与 `SelectionOverlayConfiguration`

- 创建浮层时读取“恢复最近隐藏的贴图”的当前启用状态和快捷键。
- 把动态贴图快捷键传入浮层，供事件匹配和工具提示共同使用。

## 测试策略

测试先行，覆盖以下行为：

1. 单独 `F1` 和 `F12` 可应用、注册并持久化。
2. 不带修饰键的普通字母或数字仍被拒绝。
3. 固定工具条快捷键返回具体冲突动作，且不改变任何注册或设置。
4. `Shift+S` 按工具条实际匹配规则与“矩形”冲突。
5. 可配置冲突在未确认时不改变状态。
6. 确认覆盖后，新动作获得快捷键，旧动作被禁用并持久化为空。
7. 覆盖注册失败或保存失败时，双方完整回滚。
8. 覆盖“恢复最近隐藏的贴图”后，动态贴图快捷键为空。
9. 将“恢复最近隐藏的贴图”改为 `F1` 后，工具条事件匹配和括号提示都显示并响应 `F1`。
10. 中英文固定冲突和覆盖确认文案都包含冲突动作名称。
11. 现有快捷键禁用、恢复默认、捕获期间暂停注册、菜单显示和工具条其他快捷键测试保持通过。

## 非目标

- 不开放矩形、箭头线、画笔等固定工具条快捷键的自定义设置。
- 不改变 macOS 已被其他应用或系统占用时的 Carbon 注册失败处理。
- 不尝试绕过 macOS 对媒体键、亮度键等特殊硬件按键的系统限制。
- 不修改文字标注、截图、贴图生成或标注工具本身的业务行为。
