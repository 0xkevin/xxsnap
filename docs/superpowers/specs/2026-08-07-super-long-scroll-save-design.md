# 超长滚动截图无损保存与进度交互设计

## 目标

同时解决三个已确认问题：超长截图保存后的清晰度可信度、超过 29,000 像素时提示框的视觉与排版、保存期间缺少真实进度和明确取消入口。

## 已确认的产品行为

- 截图高度首次超过 29,000 像素时，只显示一次窄版超长截图提示。
- 提示框采用 A 方案：约 348 像素宽的 macOS 浅色卡片；只有标题居中，正文、说明与限制左对齐并自动换行。
- 进入超长模式后只支持直接保存 PNG，不再进入长图编辑器。
- 用户选择保存位置后显示保存进度卡片，百分比来自实际已编码像素行数。
- 保存期间按 Esc 不产生任何动作，只有点击“取消保存”才会取消。
- 点击“取消保存”后立即请求编码器停止；编码器退出后删除未完成文件、结束本次滚动截图并丢弃本次结果，不返回滚动截图界面。
- 保存成功后才让目标文件可见，并在 Finder 中定位该文件。

## 清晰度与导出架构

现有屏幕预览通过 `preview(maximumHeight: 1_200)` 生成，仅用于界面显示。最终导出不得读取该预览。最新实测文件 `xxsnap_截图_20260807_143102.png` 的实际尺寸为 2332×100353，证明当前直接保存路径使用了完整像素尺寸；100% 像素裁切中的文字边缘也保持清晰。整张超长图适应窗口时低于 1% 的显示比例，以及部分查看器的超长图缩略解码，会让视觉上看起来模糊，但不能把查看器行为当成导出正确性的唯一依据。

新的导出实现以可测试的像素等价性为准：

1. 拼接核心按从上到下的顺序提供最终 BGRA 像素行，包含待提交尾帧、滚动条裁剪和接缝修复。
2. PNG 编码器把每一行从预乘 BGRA 转成 PNG 所需的非预乘 RGBA，不做尺寸缩放。
3. 编码器使用 PNG 无损过滤和 zlib 压缩，把一个连续 zlib 数据流分批写入 IDAT 块。
4. 进度按已编码行数除以总行数计算；写完 IEND 并同步文件后才报告 100%。
5. 测试同时校验 PNG 像素宽高、解码后的像素内容和核心最终像素一致，防止误用预览或引入重采样。

## 原子保存与取消

编码器在目标文件同一目录创建唯一的隐藏 `.part` 临时文件。保存成功后，使用文件系统替换/移动操作把临时文件原子地变为用户选择的目标文件。这样保存失败或应用退出时不会留下看似正常但已损坏的 PNG。

取消信号使用线程安全的原子标志，从进度窗口一路传递到 Objective-C++ PNG 编码循环。编码器在取像素行、压缩输出和写文件之间检查取消标志。取消或编码失败时关闭文件并删除 `.part`；若目标位置已有旧文件，旧文件在新文件完整成功前保持不变。

## 界面状态

### 超长提示

- 标题：`即将进入超长截图模式`
- 正文：`当前截图高度已超过 29,000 像素。继续截图后，将仅支持保存为 PNG。`
- 说明：`图片仍按原始像素无损保存。部分图片查看器可能只显示低清预览，或无法完整处理超长图片。`
- 限制：PNG 最高支持 2,000,000 像素高度；无需继续时点击工具栏对勾。
- 主按钮：`继续截图`

英文界面提供等义文案。窗口正文宽度固定、垂直高度由内容决定，所有长文本使用按词换行。

### 保存进度

- 标题：`正在保存长截图`
- 状态：`正在写入 PNG`
- 内容：真实百分比、进度条和省略中间路径的目标文件位置。
- 辅助说明：`保存期间按 Esc 不会取消`
- 破坏性操作：底部单独的红色 `取消保存` 按钮。

点击取消后按钮立即禁用并显示正在取消，直到后台编码真正退出。成功、失败和取消都会关闭进度窗口；只有失败进入可重试状态，用户主动取消直接结束截图。

## 错误与边界

- PNG 高度超过 2,000,000 像素时停止继续采集并要求保存当前结果，避免超出产品支持范围。
- 目标目录不可写、磁盘空间不足、zlib 错误或文件替换失败时，删除临时文件并显示保存失败；保留拼接会话以允许用户重新选择位置保存。
- 保存面板本身被取消时不开始编码，并返回当前滚动截图界面，仍可再次点击完成。
- 保存进行中切换窗口不会影响编码，因为像素已在本地拼接存储中；Esc 被保存窗口消费，不传播给截图取消逻辑。

## 验收标准

- Retina 输入导出的 PNG 像素宽高与拼接核心输出完全一致，不等于预览尺寸。
- 解码后抽样像素行与拼接核心逐字节等价；透明像素按预乘/非预乘规则保持相同视觉结果。
- 100,000 像素以上 PNG 可以保存、重新解码，并保持原始宽度和高度。
- 进度单调递增且最终为 100%，长图保存期间持续更新。
- 点击取消后不生成目标文件，不残留 `.part` 文件，并结束滚动截图。
- 目标文件已存在时，取消或失败不会破坏旧文件。
- 超长提示宽度不超过 380 像素，标题居中，正文左对齐且无截断。
- 保存进度窗口按 Esc 不关闭、不取消；取消按钮只触发一次。
