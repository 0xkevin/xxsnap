# 截图与贴图两级 ESC 退出设计

## 目标

截图区域和贴图编辑统一采用状态驱动的两级 ESC：第一次退出当前持续工具或未完成操作，第二次在基础区域关闭当前窗口。该行为不依赖两次按键的时间间隔。

## 状态与行为

持续工具包括矩形/椭圆、箭头、画笔、标记、取色/测距、马赛克、文字、编号、放大镜和橡皮擦。只要任一持续工具、工具草稿、文字编辑、数值编辑或工具选项面板处于活动状态，ESC 就由编辑浮层消费并执行以下动作：

- 丢弃尚未完成的形状、画笔、马赛克、橡皮擦矩形和文字空草稿。
- 结束非空文字编辑并保留已输入内容。
- 关闭颜色、线型、圆角、箭头、文字、编号、放大镜和马赛克选项面板。
- 清除活动工具和标注选中状态，返回已锁定截图区域或贴图的基础状态。
- 保留所有已经完成的标注及橡皮擦结果。

Undo、Redo、复制、保存、贴图、滚动截图和完成/取消按钮属于一次性动作，不作为活动工具。

当编辑浮层已处于基础状态时：

- 普通截图的 ESC 关闭截图区域并返回取消结果。
- 贴图编辑的 ESC 关闭当前整张贴图窗口，而不是只隐藏工具条。
- 未打开工具条的贴图继续保持 ESC、Delete 和 Backspace 关闭当前贴图的既有行为。

如果第一次 ESC 后重新激活工具，下一次 ESC 仍只退出新工具，不关闭窗口。

## 实现边界

在 `SelectionOverlayView` 集中提供 ESC 状态消费方法，先于工具条快捷键匹配运行。方法只根据当前状态返回“已消费”或“基础状态”，不引入计时器、全局监听或渲染循环。

`SelectionOverlayWindow` 在浮层未消费 ESC 时执行第二级行为：普通截图沿用取消完成；贴图通过现有窗口命令回调关闭当前贴图。工具的清理复用既有草稿、文本、测距、下拉框和光标刷新方法。

## 验收

- 每个持续工具激活后第一次 ESC 均停用工具且窗口保持打开。
- 普通截图基础状态下下一次 ESC 关闭截图区域。
- 贴图基础状态下下一次 ESC 关闭整张贴图。
- 未完成草稿被丢弃，已完成标注保持不变。
- 一次性动作和其他键盘快捷键行为不变。
- 不新增轮询、计时器或持续性能开销。
