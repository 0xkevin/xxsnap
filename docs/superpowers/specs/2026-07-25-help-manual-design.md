# XxSnap 帮助手册设计

## 背景

XxSnap 已经包含区域截图、全屏截图、滚动截图、贴图、文字识别和教笔等功能，但应用内还没有一份面向普通用户的完整使用说明。现有 `docs/annotation-tools-user-guide.md` 记录了标注工具的详细行为，适合作为内容依据，但它不是用户可以从菜单中直接打开的帮助界面，也没有覆盖当前全部独立功能。

本次功能在顶部状态栏菜单中新增“帮助…”，打开独立的原生帮助窗口。第一阶段只编写和交付中文版；中文内容经过用户确认后，再补充英文版。

## 目标

- 在状态栏菜单“关于…”上方新增“帮助…”。
- 提供独立的 `XxSnap 帮助` 窗口，不占用设置窗口的标签页。
- 按“截图、贴图、文字识别、教笔”四个章节组织内容。
- 使用普通用户容易理解的中文，避免产品术语堆砌和模板化表达。
- 每章同时提供功能说明、操作步骤、快捷键、注意事项和常见问题。
- 截图章节完整介绍区域截图、全屏截图、滚动截图及所有标注工具。
- 使用真实 XxSnap 界面配图，并确保图片背景为纯色，不出现桌面壁纸、其他窗口或无关图片。
- 为后续英文翻译保留清晰的数据和资源边界。

## 非目标

- 第一阶段不编写英文正文。
- 第一阶段不提供全文搜索、打印、导出 PDF、在线帮助或远端内容更新。
- 不把帮助页并入“偏好设置”窗口。
- 不从网络加载正文或图片。
- 不改变截图、贴图、OCR、教笔及其快捷键的现有行为。

## 菜单

状态栏菜单下半部分排列如下：

1. 偏好设置…
2. 检查更新…
3. 支持开发者 ☕️
4. 帮助…
5. 关于…
6. 退出

“帮助…”不设置默认快捷键。点击后打开帮助窗口；重复点击时复用现有窗口并将其带到最前方，不创建多个帮助窗口。

后续英文菜单项使用 `Help...`，但英文正文不在第一阶段交付。

## 窗口设计

### 基本结构

- 窗口标题为 `XxSnap 帮助`。
- 使用原生 AppKit 窗口，默认大小约为 `980 × 700`，允许调整大小，并设置保证正文可读的最小尺寸。
- 左侧为固定章节导航，依次显示“截图、贴图、文字识别、教笔”。
- 右侧为当前章节正文，可独立纵向滚动。
- 当前章节使用系统蓝色浅底选中状态，不使用装饰性渐变。
- 切换章节时保留每个章节在本次窗口打开期间的阅读位置。
- 关闭窗口后再次打开时默认显示“截图”章节，不持久化上次阅读位置。

### 正文层级

每个章节按以下顺序组织：

1. 一段简短说明：这个功能适合解决什么问题。
2. 本章目录：列出主要小节。
3. 常用快捷键：表格显示动作和快捷键。
4. 功能总览图。
5. 逐项说明和操作步骤。
6. 容易弄错的地方和使用提示。
7. 常见问题。

正文使用系统字体。标题、正文、图片说明和提示信息保持清楚的字号层级；正文不使用营销式大标题。

### 图片查看

- 正文图片按可用宽度等比例缩放。
- 点击图片打开窗口内的大图查看层。
- 大图保持比例并限制在当前屏幕可见范围内。
- 再次点击、按 `Esc` 或点击关闭按钮退出大图。
- 大图查看不会改变当前章节和滚动位置。

## 中文内容范围

### 截图

截图章节包含：

- 区域截图：从菜单或快捷键启动、拖动框选、移动选区、调整尺寸、取消。
- 全屏截图：直接截取当前可见桌面、包含菜单栏和 Dock、右下角预览、打开全屏截图编辑器。
- 滚动截图：选择滚动区域、开始采集、手动滚动、方向锁定、预览回看、完成或取消、长图编辑及使用限制。
- 截图完成后的通用操作：复制、保存、贴图、撤销、重做和取消。
- 标注工具：
  - 取色与测距
  - 矩形、圆形和椭圆
  - 箭头线
  - 画笔
  - 荧光笔
  - 马赛克
  - 文字
  - 序号、对勾和叉号
  - 放大镜
  - 橡皮擦
- 常见问题：选区调整、暗色背景、标注编辑、滚动截图不增长、固定头部、资源上限、保存失败等。

章节开头显示区域截图、全屏截图、复制、保存、贴图和取消等快捷键。涉及快捷键的具体步骤中再次显示对应按键。

### 贴图

贴图章节包含：

- 从普通截图、全屏截图或长截图创建贴图。
- 贴图初始位置和显示内容。
- 拖动移动、滚轮或触控板缩放。
- 右键菜单中的显示工具条、复制图片、保存图片、重置大小、透明度、置顶、关闭和关闭全部。
- 显示工具条后继续添加标注，并说明完成编辑后的结果。
- 使用 `Esc` 或 `Delete` 隐藏贴图，以及恢复最近隐藏贴图的快捷键。
- 多张贴图同时存在时的操作规则。
- 常见问题：贴图挡住内容、缩放过大或过小、找回隐藏贴图、贴图是否进入复制结果等。

### 文字识别

文字识别章节包含：

- 从菜单或快捷键启动“识别文字”。
- 拖动框选后自动开始识别，不显示工具栏。
- 识别成功后自动复制到剪切板。
- 成功提示、失败提示和提示音的默认行为。
- 设置中的“禁用识别文字提示音”和“禁用识别文字通知”分别控制什么。
- 横排文字、竖排文字及中、英、韩混合内容的基本支持情况。
- 在截图编辑器、长截图编辑器、全屏截图编辑器和教笔使用期间单独调用文字识别。
- 常见失败原因：选区太小、文字模糊、对比度低、字号过小、特殊艺术字体、语言混排过于复杂。
- 提高识别率的方法：只框文字、保留完整字形、适当扩大选区、避免把无关图形一同框入。
- 隐私说明：当前 OCR 在本机完成，不上传截图。

### 教笔

教笔章节包含：

- 从菜单或快捷键进入、再次使用快捷键退出。
- 启动后直接使用默认画笔，页面保持原本显示效果。
- 右键呼出紧凑工具栏，再次右键或点击画布隐藏工具栏。
- 可用工具：画笔、形状、箭头、荧光笔、文字、序号、马赛克、取色、橡皮擦、放大镜、复制和保存。
- 工具选项：粗细、颜色、线条、形状和其他当前可调整项。
- 标注选择、移动、删除及清除方式。
- 复制和保存时如何包含当前全屏内容与标注。
- 教笔运行期间调用区域截图、全屏截图和文字识别的规则。
- 文字识别期间教笔标注保持可见，识别完成后继续使用，已有标注不丢失。
- 多显示器和退出相关注意事项。
- 常见问题：工具栏找不到、右键无反应、标注看不清、文字识别结束后如何继续标注等。

## 快捷键显示

- 帮助内容中的默认快捷键来自结构化内容文件，并与当前默认设置保持一致。
- 每章开头显示该功能相关快捷键表。
- 操作步骤中的快捷键使用键帽样式显示。
- 帮助正文明确说明快捷键可以在“偏好设置 → 快捷键”中修改。
- 第一阶段帮助页显示默认快捷键，不读取用户自定义快捷键。这样文档内容可稳定校对；设置页面仍是当前实际快捷键的唯一准确信息来源。

## 配图规范

### 组织方式

采用“总览图 + 关键步骤图”：

- 每章至少一张总览图，先说明完整界面和主要区域。
- 容易误操作或只靠文字不易理解的步骤单独使用近景图。
- 简单操作不为凑数量重复配图。
- 总览图中的数字标记与图片下方说明一一对应。

### 视觉要求

- 使用实际运行中的 XxSnap 界面截图，不使用概念图代替真实功能。
- 图片背景只能使用统一纯色，优先使用浅灰、浅蓝或浅绿色。
- 图片中不出现桌面壁纸、其他应用窗口、个人信息或其他底图。
- 不把多张截图叠在一起，不使用带阴影的装饰性背景图。
- 需要强调的位置使用红色圆形数字标记；不使用大段箭头文字遮挡界面。
- 图片按 Retina 清晰度准备，并以无损 PNG 保存。
- 图片文件名使用稳定英文标识，例如 `capture-overview.png`、`ocr-selection.png`。

### 第一阶段图片清单

截图：

- 区域截图总览
- 选区移动与调整
- 截图主工具栏总览
- 标注工具分组总览
- 全屏截图右下角预览
- 全屏截图编辑器
- 滚动截图采集中
- 长截图编辑器

贴图：

- 贴图窗口总览
- 贴图右键菜单
- 贴图工具栏
- 贴图缩放与透明度

文字识别：

- 文字识别框选
- 识别成功提示
- 识别失败提示
- 设置中的声音和通知选项

教笔：

- 教笔画布总览
- 右键紧凑工具栏
- 工具选项栏
- 教笔与文字识别同时使用

实际制作时可以合并信息重复的近景图，但不能删除四个章节的总览图。

### 数据模型

帮助内容使用可解码的结构化 JSON，顶层包含：

- 文档版本
- 语言
- 窗口标题
- 章节列表

每个章节包含：

- 稳定章节 ID
- 导航标题
- 页面标题
- 简介
- 本章目录
- 快捷键列表
- 内容块列表

内容块支持：

- 标题
- 普通段落
- 编号步骤
- 无序列表
- 快捷键表
- 图片和图片说明
- 提示
- 警告
- 常见问题

Swift 代码只负责解码、渲染和交互，不硬编码长篇帮助正文。

## 组件边界

### `HelpWindowController`

- 创建和复用帮助窗口。
- 管理左侧章节选择、各章滚动位置和图片大图查看。
- 根据当前应用语言选择内容资源；第一阶段英文语言仍显示中文内容，并在英文阶段再切换为英文资源。

### `HelpContentLoader`

- 从应用包读取指定 JSON。
- 解码并验证章节 ID、内容块和图片引用。
- 返回可渲染内容或明确错误。

### `HelpContentView`

- 渲染当前章节。
- 使用 `NSScrollView` 和垂直内容布局承载长文。
- 根据内容块类型生成对应的原生 AppKit 视图。
- 图片随正文宽度等比例调整，文字不会被图片覆盖。

### `HelpImagePreviewController`

- 显示点击后的大图。
- 处理 `Esc`、再次点击和关闭按钮。
- 不拥有或修改帮助正文状态。

### `StatusItemController`

- 新增“帮助…”菜单项和打开帮助的回调。
- 保持现有菜单项行为不变。

## 数据流

1. 用户点击状态栏菜单“帮助…”。
2. `StatusItemController` 调用应用层提供的 `showHelp` 回调。
3. `HelpWindowController` 加载当前语言对应的帮助内容。
4. 内容加载成功后，窗口默认显示“截图”章节。
5. 用户切换章节时，控制器记录旧章节滚动位置并渲染新章节。
6. 用户点击图片时，图片预览控制器显示同一资源的大图。
7. 关闭帮助窗口只释放窗口显示状态，不影响截图、贴图、文字识别或教笔会话。

## 错误处理

- 中文 JSON 无法读取或无法解码时，打开一个最小错误页，显示“帮助内容暂时无法打开”，不导致应用退出。
- 单张图片缺失时，在原位置显示“图片暂时无法显示”，其余文字和章节继续可用。
- 未知内容块类型由解码阶段报告错误，不静默渲染错误布局。
- 章节列表为空时使用错误页，不显示空白窗口。
- 图片尺寸异常时按可用宽度缩放，不让窗口被图片撑大。
- 帮助窗口异常不会中断当前贴图、长图编辑器或教笔；帮助是独立窗口。

## 测试

### 单元和界面结构测试

- 中文和英文菜单标题正确。
- “帮助…”位于“关于…”上方。
- 点击菜单调用帮助窗口，而不是设置窗口。
- 重复点击复用同一帮助窗口。
- 中文 JSON 可以解码，并包含四个稳定章节 ID。
- 截图章节包含区域、全屏、滚动和全部标注工具。
- 每章包含快捷键块、总览图和常见问题。
- 章节切换保留本次会话中的滚动位置。
- 图片点击打开预览，`Esc` 关闭预览。
- 缺失图片时显示回退文字。
- JSON 损坏、章节为空时显示错误页。

### 手工验收

- 在中文界面中从状态栏菜单打开帮助。
- 检查窗口最小尺寸和常用桌面尺寸下的排版。
- 检查四章滚动、切换和滚动位置恢复。
- 检查所有图片清晰、背景为纯色且没有无关内容。
- 检查正文和按钮没有重叠，长标题不会被截断。
- 在截图、贴图、文字识别、教笔和长图编辑窗口存在时打开帮助，确认互不影响。

## 验收标准

- 状态栏菜单“关于…”上方出现“帮助…”。
- 帮助窗口采用已确认的左侧导航布局。
- 中文版包含截图、贴图、文字识别和教笔四个完整章节。
- 截图章节逐项介绍全部已支持标注工具。
- 所有相关快捷键既有章节汇总，也出现在对应操作步骤中。
- 配图采用已确认的“总览图 + 关键步骤图”，背景全部为纯色。
- 正文使用自然、直接、面向普通用户的中文。
- 内容、图片和 Swift 界面代码相互分离。
- 内容或单张图片加载失败时不会影响应用其他功能。
- 相关自动化测试通过，并完成应用内手工检查。

## 英文阶段

中文版完成后，先由用户审核全部中文文案和配图。确认无误后：

1. 以最终中文结构为基准创建 `en.json`。
2. 使用自然英文重写，不逐字直译中文句式。
3. 根据英文界面重新制作必要配图。
4. 让帮助窗口跟随应用语言自动选择中文或英文内容。
5. 运行两种语言的结构和视觉测试。
