# 长截图 20 万像素停止与保存退场设计

## 目标

- 正常长截图流程保持不变。
- 当一次成功拼接使输出高度超过 200,000 物理像素后，保留这次完整拼接结果并立即停止后续采样。
- 不在 200,000 像素以下提前停止，也不裁剪最后一次成功拼接。
- 使用明确的“已达到最大高度”提示，避免误报为拼接失败或资源不足。
- 超长截图开始保存后，立即关闭截图选区、遮罩和滚动预览，只保留保存进度窗口，让桌面恢复正常。

## 状态设计

`ScrollCaptureSession` 新增独立的最大高度暂停原因。每次接受有效追加并更新预览后，检查输出高度：

- `outputHeight <= 200_000`：继续捕获。
- `outputHeight > 200_000`：保留当前结果，停止采样，进入最大高度暂停状态。

最大高度暂停仍允许用户点击完成并直接保存。该状态不复用资源上限或匹配失败状态。

## 提示文案

达到限制时显示：

> 已达到长截图最大高度 200,000 像素，已停止继续滚动，请完成并保存当前截图。

29,000 像素超长模式说明同步声明：长截图超过 200,000 像素后会停止继续拼接，图片仍按原始像素无损保存。

## 保存退场

用户选择保存位置后：

1. 创建并显示保存进度窗口。
2. 立即停止滚动预览并关闭截图选区遮罩。
3. 释放冻结桌面背景，但保留拼接会话和编码任务。
4. 保存成功后关闭进度窗口并清理会话。
5. 用户点击取消时终止编码、删除未完成结果并清理会话。

保存位置选择器被取消时不退场，仍保留当前截图，用户可以再次点击完成。

## 回归保护

- 200,000 像素及以下继续采样。
- 首次超过 200,000 像素后才停止，且不会继续捕获新帧。
- 达到上限后仍可保存已拼接内容。
- 普通长度截图与 29,000 像素提示流程不变。
- 保存进度出现时截图遮罩和滚动预览已经退出，进度窗口及取消操作仍正常工作。
