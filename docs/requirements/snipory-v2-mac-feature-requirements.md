# xxsnap Mac 功能需求说明书

> 文档状态：持续维护中  
> 最后更新：2026-06-27  
> 适用范围：`xxsnap/` native-shell 重写版本，当前以 macOS 实现为事实基准，并作为后续 Windows native shell 开发的产品规格来源。
> 配套原型：`docs/prototypes/` 中的 capture overlay prototype（历史文件名暂未迁移）

## 1. 文档目标

这份需求说明书沉淀 xxsnap mac 已完成和正在形成的产品能力，降低后续开发 Windows 版本时反复编写提示词、重复解释交互细节和遗漏规则的成本。

后续开发原则：

- macOS 版本每完成一个截图、标注、导出、贴图、OCR 或滚动截图能力，必须同步更新本文。
- Windows 版本实现时，优先复刻本文定义的用户目标、交互规则、工具状态、导出结果和验收标准。
- 若 macOS 当前代码行为与早期设计文档不一致，以最新代码、测试和用户指南为准，并把本文更新为新的事实来源。
- 本文不替代实现计划；实现计划仍应按具体功能拆分，但不得重新发明本文已确定的产品行为。

## 2. 产品定位

Snipory 是一款截图、贴图、标注、OCR 和滚动截图工具。v2 方向是用 native 平台壳承载共享核心能力：

- `core/`：共享 C++ 核心，承载跨平台数据模型、几何、渲染和导出用例。
- `platforms/mac/`：当前主实现，使用 Swift/AppKit 承载 macOS 原生截图叠层、工具栏和平台行为。
- `platforms/win/`：Windows native shell 脚手架，后续应复刻本文定义的核心体验。

产品体验目标：

- 截图路径要快：用户从启动截图到复制/保存应尽量少操作。
- 标注工具要可编辑：已完成的标注应能选中、移动、删除，并在适用时调整样式或几何。
- 预览和导出一致：叠层中看到的标注效果应出现在复制/保存结果中。
- 平台壳原生：权限、窗口、剪贴板、保存面板、鼠标指针、菜单栏和后续贴图窗口由平台层负责。
- 共享规则前置：工具语义、几何、颜色、导出裁剪和验收规则应尽量平台无关，减少 Windows 复刻歧义。

## 4. 核心截图流程

### 4.1 启动与权限

- 用户触发截图后，macOS 版本进入全屏截图叠层。
- macOS 层负责 ScreenCaptureKit、屏幕录制权限、当前桌面截图和窗口信息读取。
- 若权限缺失，应引导用户授权，而不是让叠层进入无图或不可操作状态。
- Windows 版本应使用 Windows 原生截图能力，并把权限/屏幕 API 隔离在 `platforms/win/` 内。

### 4.2 选择区域

- 用户拖拽创建截图选区。
- 选区未锁定前，应显示选择反馈并支持 `Esc` 取消。
- 松开鼠标后锁定选区，并显示主工具栏与选区尺寸控制。
- 导出图片只包含锁定选区内的像素；标注可以在编辑时越界显示，但复制/保存时按选区裁剪。

### 4.3 选区控制

已锁定选区应支持：

- 拖拽选区内部移动选区。
- 拖拽边缘或角点调整选区大小。
- 切换选区角样式：直角/圆角。
- 锁定或解除长宽比。
- 刷新截图内容，刷新时应忽略 Snipory 自身叠层窗口。
- 工具激活时，选区边缘的缩放命中优先级仍应高于绘制工具。

### 4.4 取色器

- 没有启用标注工具且还没有添加标注时，选区内显示取色信息。
- 取色显示包括颜色样本、HEX/RGB 文本、复制提示和切换提示。
- `C` 复制当前颜色值。
- `Shift` 在 HEX 和 RGB 模式之间切换。
- 取色应读取原始截图像素，并在需要时转换到 sRGB，避免显示颜色偏移。

## 5. 工具栏体系

### 5.1 主工具栏

主工具栏按钮顺序：

1. 形状标注
2. 箭头线
3. 画笔
4. 标记
5. 马赛克
6. 文字
7. 序号
8. 放大镜
9. 橡皮擦
10. 滚动截图（仅 feature gate 开启时显示）
11. 撤销
12. 重做
13. 取消
14. 贴图
15. 保存
16. 复制到剪切板
17. 设置/更多

主工具栏规则：

- 主工具栏可拖动，左侧拖拽柄和右侧设置按钮区域都可作为移动手柄。
- 形状、箭头线、画笔、标记、马赛克互斥激活。
- 已激活工具的图标使用蓝色选中态，不再依赖明显的选中背景块。
- 未实现工具点击后只能显示“功能开发中”类提示，不得改变已实现工具状态。
- 撤销、重做、复制、保存、取消是命令按钮，不参与工具互斥状态。

### 5.2 选项工具栏

- 已实现标注工具激活或选中相应标注时，显示工具专属选项工具栏。
- 所有选项工具栏高度与主工具栏保持一致的紧凑视觉。
- 选项工具栏左右内边距为 10px。
- 只显示当前工具真正可用的控件，避免把形状、箭头、画笔、标记、马赛克的选项混在一起。
- 工具切换时，关闭不属于当前工具的弹出菜单或面板。

## 6. 通用标注规则

### 6.1 标注模型

mac 当前已使用的标注类型：

- `rectangle`
- `ellipse`
- `arrowLine`
- `brush`
- `marker`
- `mosaicStroke`
- `mosaicRectangle`

通用要求：

- 标注坐标以锁定选区为本地坐标基准。
- 移动选区后，已有标注在屏幕上的相对视觉位置应保持正确。
- 标注可以在选区外预览或编辑，但导出时按截图图片边界裁剪。
- 复制和保存应使用同一渲染规则，避免预览和最终图片不一致。

### 6.2 选择、移动、删除

- 点击已完成标注可选中它。
- 选中标注后，选项工具栏切换到该标注类型。
- 可拖动标注本体移动标注。
- `Delete` 删除当前选中标注。
- 点击其他标注会切换选中对象。
- 绘制新标注时不应误移动已有标注，除非当前命中明确是已有标注的可编辑区域。

### 6.3 撤销与重做

- `Command + Z` 撤销。
- `Command + Shift + Z` 重做。
- 工具栏撤销/重做按钮与快捷键行为一致。
- 新增、删除、移动、适用工具的样式编辑和几何编辑应进入历史。
- 删除或样式修改后，如无法安全重做，应清空 redo 栈，避免恢复到不一致状态。

### 6.4 颜色与线宽

- 默认调色板按两排展示。
- 第一项红色用于形状、箭头线、画笔等非标记工具的默认强调色。
- 标记笔默认颜色为 `#B3EB00`。
- 支持自定义颜色入口。
- 线宽按钮展示“细/中/粗”，但不同工具的实际数值不同，不能跨工具混用。

## 7. 已实现工具需求

### 7.1 形状标注

用户目标：框选界面区域、突出按钮、强调截图局部。

能力：

- 支持矩形和椭圆。
- 默认矩形。
- 从任意方向拖拽创建形状。
- 支持线宽 `2 / 4 / 7`。
- 支持填充开关。
- 支持实线、虚线、点线、长短虚线、手绘风格等线型；高级手绘线型可受 feature gate 或权限控制。
- 支持调色板和自定义颜色。
- 矩形支持圆角，范围 `0...30`，默认圆角值为 `5`。

编辑：

- 点击形状边框选中。
- 拖动边框移动整个形状。
- 拖动边缘或角点调整大小。
- 选中后可继续修改线宽、颜色、填充、线型、矩形/椭圆模式和矩形圆角。
- 形状边框命中应忽略大面积内部，避免用户在嵌套区域中绘制新标注时被已有形状抢走输入。

### 7.2 箭头线

用户目标：指向截图中的具体位置，用于步骤说明、问题定位和视觉指引。

能力：

- 点击“箭头线”激活。
- 按下为起点，拖拽到目标位置，松开生成箭头线。
- 新箭头线默认是直线；中间控制点位于起止点中点。
- 拖动控制点可变为二次曲线。
- 默认线宽为中线，实际值 `4`。
- 默认颜色为调色板第一项红色。
- 默认起点箭头为无箭头，终点箭头为普通箭头。
- 支持线型和颜色。

箭头类型：

- 无箭头实线
- 普通箭头线
- 实心箭头线
- 空心箭头线
- 菱形箭头线
- 端帽箭头线
- 圆点箭头线

规则：

- 起点和终点箭头下拉菜单包含同一组选项。
- 特殊箭头类型在起点和终点之间存在互斥规则时，应保持与 mac 当前实现一致。
- 起点预览朝左，终点预览朝右。

编辑：

- 点击线体选中并移动整条箭头线。
- 拖动起点或终点调整长度和方向。
- 拖动控制点调整曲率。
- 选中后可修改线宽、线型、颜色、起点箭头和终点箭头。

### 7.3 画笔

用户目标：自由手绘、圈画不规则区域、手写短线、快速涂画提示。

能力：

- 点击“画笔”激活，鼠标变为画笔样式。
- 按下并自由拖动形成路径，松开后生成画笔标注。
- 按住 `Shift` 拖动时，生成从按下点到松开点的直线。
- 默认颜色为调色板第一项红色。
- 线宽为 `3 / 5 / 7`，默认中线 `5`。
- 支持实线和常用虚线类型。
- 不显示填充、形状切换和箭头类型。

编辑：

- 点击路径选中。
- 拖动画笔路径移动整条路径。
- 画笔两端附近有内收的方向调整手柄，用于围绕相对端旋转/调整路径方向。
- 完成后不支持像形状那样缩放边框。
- 完成后样式冻结，不支持修改已画路径的线宽或颜色；需要不同样式时先设置再绘制。

### 7.4 标记笔

用户目标：像荧光笔一样高亮文字、表格行、代码行或标题。

能力：

- 点击“标记”激活。
- 鼠标为圆点，圆点颜色跟随当前标记颜色，大小跟随标记粗细的预览尺度。
- 只绘制直线。
- 普通拖动支持任意角度直线。
- 按住 `Shift` 拖动时，吸附到最近的水平、垂直或 45 度方向。
- 点击不拖动也可生成点状标记。
- 默认颜色为 `#B3EB00`。
- 线宽为 `14 / 18 / 22`，默认 `18`。
- 固定高亮混合效果，保留底下文字可读性。
- 不显示填充、形状切换、线型、箭头类型。

编辑：

- 点击标记线附近选中。
- 拖动线体移动整条标记。
- 选中后可修改颜色和粗细。
- 两端方向调整手柄向线段内部收一点，避免挡住真实端点。
- 拖动方向调整手柄可改变方向和长度。
- 单点标记可移动，不应被错误当成可缩放形状。

### 7.5 马赛克

用户目标：快速遮挡敏感内容，如头像、手机号、地址、聊天内容、表格字段和密钥。

能力：

- 点击“马赛克”激活，不再显示占位提示。
- 默认进入滑动打码模式。
- 默认打码类型为高斯模糊。
- 支持两种打码类型：
  - 高斯模糊
  - 像素马赛克
- 两种打码类型各自记住强度值。
- 强度范围为 `8...20`，默认 `8`。
- 支持两种绘制行为：
  - 滑动打码
  - 矩形打码
- 滑动打码点大小为 `15 / 30 / 40`，默认 `30`。
- 滑动打码支持点击生成点状打码。
- 滑动打码支持拖拽路径。
- 滑动打码按住 `Shift` 时，绘制轴向锁定线。
- 矩形打码支持移动、缩放和旋转。
- 打码可从选区外开始或延伸到选区外，但导出只保留选区内效果。

预览与性能：

- 马赛克预览必须叠加在已有标注和已有马赛克结果之上，不能在重叠处露出原始像素。
- 多个马赛克重叠时，后续打码不得降低先前打码强度或让内容变清晰。
- 修改马赛克强度时，使用局部预览，不应强制整张复合图重新渲染。
- 像素马赛克局部预览需要按像素块边界扩展处理区域，避免拖动强度时出现块状错位。
- 预览和导出共享同一 redaction 语义：高斯模糊和像素马赛克都必须真正改变底图像素，而不是半透明覆盖。

编辑：

- 点击滑动打码路径或矩形打码区域选中。
- 滑动打码可移动，选中后可修改打码类型、强度和点大小。
- 矩形打码可移动、缩放、旋转，选中后可修改打码类型和强度。
- 选中矩形后切换到滑动点大小，不得意外修改矩形打码参数。
- 马赛克工具栏不显示形状模式按钮、填充、线型、箭头类型或颜色。

## 8. 待实现工具需求占位

以下工具当前仍未完成。后续每个工具开发前，应先补充单独需求文档或扩展本文，然后实现、测试并回填状态。

### 8.1 文字

目标：在截图上添加可编辑文本。

最低要求：

- 点击文字工具进入文本插入模式。
- 点击选区内任意位置创建文本框。
- 支持输入、移动、删除、颜色、字号或至少三档字号。
- 导出文本应与预览一致。
- 文本输入不应抢占全局截图快捷键。

### 8.2 序号

目标：为步骤说明添加递增编号。

最低要求：

- 点击或拖拽创建编号点。
- 自动递增编号。
- 支持移动、删除和重新排序策略。
- 支持颜色和尺寸。
- 删除中间编号后的编号重排规则必须明确。

### 8.3 放大镜

目标：局部放大截图内容。

最低要求：

- 支持圆形或矩形放大区域。
- 支持倍率和尺寸调整。
- 支持移动、删除。
- 导出时放大内容与预览一致。

### 8.4 橡皮擦

目标：删除或擦除标注。

待定问题：

- 橡皮擦是删除整条标注，还是擦除标注局部？
- 是否影响原始截图像素？
- 是否与撤销/重做历史逐笔集成？

### 8.5 贴图

目标：将截图固定为桌面浮窗。

最低要求：

- 从当前选区创建置顶贴图窗口。
- 贴图应保留标注结果。
- 支持移动、缩放、关闭。
- 后续可扩展透明度、鼠标穿透、窗口层级和多贴图管理。

### 8.6 滚动截图

目标：截取超过当前屏幕可见区域的长页面或长内容。

最低要求：

- 支持选择滚动目标。
- 支持自动滚动采集和拼接。
- 支持失败恢复或手动停止。
- 输出可进入同一标注和导出流程。

### 8.7 OCR

目标：识别截图中的文字，并支持复制或辅助标注。

最低要求：

- 支持对选区或整张截图执行 OCR。
- 支持复制识别文本。
- 后续可用于自动打码建议，但不得阻塞基础标注能力。

## 9. Windows 版本迁移规则

### 9.1 必须保持一致的产品语义

Windows 版本必须复刻：

- 主工具栏按钮顺序和工具互斥规则。
- 锁定选区后的主工具栏、选项工具栏和尺寸控制关系。
- 标注类型、默认样式、线宽数值、颜色默认值和强度范围。
- 选择、移动、删除、撤销、重做、复制、保存、取消的用户结果。
- 预览和导出的视觉一致性。
- 标注越界可预览、导出裁剪到选区的规则。
- 马赛克重叠不露出原始像素的规则。

### 9.2 可以平台化实现的部分

Windows 可使用自己的平台实现：

- 截图 API。
- 窗口枚举和系统 UI 识别。
- 剪贴板写入。
- 保存文件对话框。
- 原生鼠标指针和窗口层级。
- 贴图窗口。
- 辅助功能接口。

但平台化实现不能改变本文定义的用户可见行为。

### 9.3 建议拆分

Windows 开发建议按以下顺序推进：

1. 区域截图、锁定选区、复制和取消。
2. 主工具栏和选项工具栏布局。
3. 形状标注。
4. 箭头线。
5. 画笔。
6. 标记笔。
7. 马赛克。
8. 保存 PNG。
9. 贴图。
10. 文字、序号、放大镜、橡皮擦。
11. 滚动截图和 OCR。

## 10. 验收标准

### 10.1 自动化验证

mac 当前推荐命令：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project platforms/mac/xxsnap.xcodeproj -scheme xxsnap -configuration Debug -derivedDataPath build/xcode-derived test
```

截至 2026-06-27，本分支最近一次验证结果：

- `xxsnapTests` 执行 `298` 个测试。
- `0` failures。
- `TEST SUCCEEDED`。

Windows 后续应建立等价验证：

- 几何和渲染使用平台无关测试或共享核心测试。
- 平台壳使用 Windows UI/集成测试覆盖选区、工具栏、输入、导出。
- 每个工具至少覆盖默认状态、绘制、选择、编辑、删除、撤销/重做、导出。

### 10.2 手动冒烟

每次涉及截图叠层或工具栏变更，至少手动检查：

- 启动截图并创建选区。
- 移动和缩放选区。
- 激活每个已实现工具。
- 绘制、选中、移动、删除每种标注。
- 修改对应工具的样式或参数。
- 撤销和重做。
- 复制到剪贴板。
- 保存 PNG。
- `Esc` 取消。
- 切换未实现工具时不会破坏当前已实现工具。

### 10.3 视觉验收

- 工具栏文字和图标不重叠。
- 选项工具栏只显示当前工具相关控件。
- 选中态明显但不过度遮挡图标。
- 标注控制点、旋转点和选区缩放点命中优先级清晰。
- 马赛克预览不闪烁、不露出原图、不因强度调整造成明显卡顿。
