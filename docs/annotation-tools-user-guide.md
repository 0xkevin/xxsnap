# xxsnap 标注工具使用说明

> 文档状态：持续维护中。本文面向最终用户，后续工具栏里每完成一个新工具，就在“已支持的标注工具”中追加对应章节。

## 适用范围

本文说明 xxsnap 截图后的标注工具用法。目前已支持 7 个标注功能：

1. 形状标注：矩形、圆形
2. 箭头线
3. 画笔
4. 标记笔
5. 马赛克
6. 文字
7. 序号

放大镜、橡皮擦、贴图、滚动截图等工具仍在开发中，后续完成后会补充到本文。

## 基本流程

1. 启动截图后，在屏幕上拖拽选择需要截取的区域。
2. 松开鼠标后，截图区域会被锁定，工具栏会显示在截图区域附近。
3. 点击工具栏中的标注工具，进入对应的绘制模式。
4. 在截图区域内按住鼠标并拖动，松开后生成标注。
5. 标注完成后，可以复制到剪切板或保存为图片。

如果只需要截图，不需要标注，可以直接点击“复制到剪切板”或“保存”。

## 通用操作

### 选择与编辑

- 点击已画好的标注，可以选中它。
- 选中标注后，工具栏会切换到该标注对应的选项。
- 选中标注后，可以拖动标注本体来移动位置。
- 选中标注后，可以点击颜色块或自定义颜色来修改颜色。
- 选中标注后，可以点击“细线 / 中线 / 粗线”修改线条粗细。
- 按 `Delete` 可以删除当前选中的标注。

### 撤销与重做

- 点击工具栏里的“撤销”可以撤销最近一次新增的标注。
- 点击工具栏里的“重做”可以恢复刚刚撤销的标注。
- 快捷键 `Command + Z`：撤销。
- 快捷键 `Command + Shift + Z`：重做。

当前撤销 / 重做主要针对标注列表的新增与恢复。删除或样式修改后，会清空可重做的内容。

### 复制、保存与取消

- 点击“复制到剪切板”或按 `Command + C`，可以把当前截图和标注复制到剪切板。
- 点击“保存”或按 `Command + S`，可以把当前截图和标注保存为 PNG 图片。
- 点击“取消”或按 `Esc`，可以退出本次截图。

导出的图片只包含最初选中的截图区域。标注在编辑时可以显示到选区边缘之外，但复制或保存时会按照截图区域裁剪。

### 颜色与取色

- 选项工具栏中的色块用于设置当前工具颜色。
- 点击最后的自定义颜色按钮，可以打开系统颜色面板选择更多颜色。
- 默认调色板分两排显示；标记笔默认使用第二排第 7 个颜色 `#B3EB00`。
- 没有启用标注工具且还没有添加标注时，截图区域内会显示取色信息。
- 取色时按 `C` 可以复制当前颜色值。
- 取色时按 `Shift` 可以在 HEX 和 RGB 显示 / 复制模式之间切换。

## 已支持的标注工具

### 1. 形状标注

形状标注用于画矩形或圆形，适合框选界面区域、突出按钮、强调截图中的局部内容。

#### 启用方式

点击工具栏中的“形状标注”按钮。启用后，会出现形状专用选项工具栏。

#### 可画内容

- 矩形
- 圆形 / 椭圆

默认进入矩形标注。可以在选项工具栏中切换矩形或圆形。

#### 绘制方式

1. 点击“形状标注”。
2. 在截图区域中按住鼠标左键。
3. 拖动到目标大小。
4. 松开鼠标生成形状。

拖拽方向不受限制，可以从任意角开始画。

#### 样式选项

形状标注支持：

- 线条粗细：细线、中线、粗线，对应实际线宽 `2 / 4 / 7`。
- 填充开关：开启后，形状内部会使用当前颜色填充。
- 形状切换：矩形、圆形。
- 线条类型：实线、虚线、手绘风格等。
- 颜色：调色板颜色或自定义颜色。
- 矩形圆角：点击矩形选项旁边的展开区域后，可以调整圆角大小，范围是 `0...30`。

#### 编辑方式

- 点击形状边框可以选中形状。
- 拖动形状边框可以移动整个形状。
- 拖动形状边缘或角上的控制点，可以调整大小。
- 选中形状后，可以继续修改线条粗细、颜色、填充、线条类型和矩形圆角。

### 2. 箭头线

箭头线用于指向截图中的具体位置，适合做步骤说明、问题定位、视觉指引。

#### 启用方式

点击工具栏中的“箭头线”按钮。启用后，会显示箭头线专用选项工具栏。

#### 绘制方式

1. 点击“箭头线”。
2. 在截图区域中按住鼠标左键，作为箭头线起点。
3. 拖动到目标位置。
4. 松开鼠标生成箭头线。

新画出的箭头线默认是直线。中间会有一个控制点，拖动控制点可以把线调整成曲线。

#### 默认样式

- 默认线宽：中线，对应实际线宽 `4`。
- 默认颜色：调色板第一项红色。
- 默认起点箭头：无箭头。
- 默认终点箭头：普通箭头。
- 默认线条类型：实线。

#### 样式选项

箭头线支持：

- 线条粗细：细线、中线、粗线，对应实际线宽 `3 / 4 / 6`。
- 线条类型：实线、虚线、手绘风格等。
- 起点箭头类型。
- 终点箭头类型。
- 颜色：调色板颜色或自定义颜色。

箭头类型包括：

- 没有箭头的实线
- 普通箭头线
- 实心箭头线
- 空心箭头线
- 菱形箭头线
- 端帽箭头线
- 圆点箭头线

#### 编辑方式

- 点击箭头线本体可以选中它。
- 拖动箭头线本体可以移动整条箭头线。
- 拖动起点或终点，可以改变箭头线长度和方向。
- 拖动中间控制点，可以把直线调整为曲线。
- 选中箭头线后，可以继续修改线条粗细、线条类型、颜色、起点箭头和终点箭头。

### 3. 画笔

画笔用于自由手绘，适合圈画不规则区域、手写短线、快速涂画提示。

#### 启用方式

点击工具栏中的“画笔”按钮。启用后，鼠标会变成画笔样式。

#### 绘制方式

1. 点击“画笔”。
2. 在截图区域中按住鼠标左键。
3. 按照需要自由拖动。
4. 松开鼠标生成画笔路径。

按住 `Shift` 再拖动时，画笔会生成一条从按下位置到松开位置的直线，适合快速画直线。

#### 默认样式

- 默认线宽：细线，对应实际线宽 `3`。
- 默认颜色：调色板第一项红色。
- 默认线条类型：实线。

#### 样式选项

画笔支持：

- 线条粗细：细线、中线、粗线，对应实际线宽 `3 / 5 / 7`。
- 线条类型：实线和常用虚线类型。
- 颜色：调色板颜色或自定义颜色。

画笔不显示填充、形状切换、箭头类型等选项。

#### 编辑方式

- 点击画笔路径可以选中它。
- 拖动画笔路径可以移动整条路径。
- 画笔两端附近有旋转手柄，拖动后可以调整画笔路径方向。
- 画笔完成后不支持像形状那样拖动边框缩放。
- 画笔完成后不支持修改已画路径的线宽或颜色；需要更换样式时，请先设置样式，再绘制新的画笔路径。

### 4. 标记笔

标记笔类似荧光笔，用于覆盖文字或区域进行高亮。它只画直线，适合标注标题、表格行、关键字段或一句文字。

#### 启用方式

点击工具栏中的“标记”按钮。启用后，鼠标会变成圆点。圆点颜色会跟随当前标记笔颜色变化，圆点大小会跟随标记笔粗细变化。

#### 绘制方式

1. 点击“标记”。
2. 在截图区域中按住鼠标左键，作为标记线起点。
3. 拖动到目标位置。
4. 松开鼠标生成一条直线标记。

标记笔只能画直线。普通拖动可以画任意角度的直线。

按住 `Shift` 再拖动时，标记线会自动吸附到最近的水平、垂直或 45 度方向。这个操作适合给整行文字、标题、表格行或代码行做整齐高亮。

#### 默认样式

- 默认颜色：第二排第 7 个颜色 `#B3EB00`。
- 默认线宽：中线，对应实际线宽 `18`。
- 可选线宽：`14 / 18 / 22`。
- 线条端点：圆角。
- 线条类型：固定为实线。

标记笔使用高亮混合效果渲染，会尽量保留底色文字的清晰度。它没有单独的透明度开关，也不会影响其他工具的默认红色。

#### 样式选项

标记笔支持：

- 线条粗细：细线、中线、粗线，对应实际线宽 `14 / 18 / 22`。
- 颜色：调色板颜色或自定义颜色。

标记笔不显示填充、形状切换、线条类型、箭头类型等选项。

选项工具栏里标记笔的粗细预览会按比例缩小显示，避免按钮里出现过粗的线条；实际画出来的标记线仍然使用 `14 / 18 / 22` 的真实线宽。

#### 编辑方式

- 点击标记线附近可以选中它。
- 拖动标记线本体可以移动整条标记线。
- 选中标记线后，可以修改颜色和粗细。
- 标记线两端附近有方向调整手柄；手柄会向线段内部收一点，避免挡住真正端点。
- 拖动方向调整手柄，可以改变标记线的方向和长度。
- 按 `Delete` 可以删除选中的标记线。

#### 使用建议

- 标注文字时，建议沿文字中线轻轻拖过一条标记线。
- 如果希望高亮线更整齐，按住 `Shift` 再拖动。
- 如果需要连续标记多行文字，先选好颜色和粗细，再逐行拖动绘制。
- 如果需要从一条标记线的端点继续接着画，可以从真实端点处重新按住鼠标拖动；方向调整手柄不会紧贴端点，方便对齐。

### 5. 马赛克

马赛克用于遮挡敏感信息，适合处理头像、手机号、地址、聊天内容、表格字段等不希望直接展示的区域。

#### 启用方式

点击工具栏中的“马赛克”按钮。启用后会立即进入滑动打码模式，默认选中中点粗细 `30`，鼠标会变成灰色圆点；如果切换到矩形打码，鼠标会变成十字准星。

#### 绘制方式

1. 点击“马赛克”。
2. 保持默认滑动模式时，在截图区域内按住鼠标并拖动，松开后生成一条连续打码路径。
3. 如果切换到矩形模式，在截图区域内按住鼠标拖出一个框，松开后生成矩形打码区域。

拖动时可以超出截图选区边界，但最终复制和保存时只会保留截图范围内的打码结果。

#### 默认样式

- 默认打码类型：高斯模糊
- 默认模糊值：`8`
- 可选模糊值范围：`8...20`
- 默认滑动点大小：中点，对应实际值 `30`
- 可选滑动点大小：`15 / 30 / 40`

数值越小，模糊程度越低、原图越容易辨认；数值越大，模糊程度越高、可见度越低。

#### 样式选项

马赛克支持：

- 打码方式：滑动打码、矩形打码
- 打码类型：高斯模糊、像素马赛克
- 打码强度：`8...20`
- 滑动点大小：细点、中点、粗点，对应 `15 / 30 / 40`

高斯模糊和像素马赛克会分别记住各自最近一次使用的强度值。第二工具条里的圆形和十字小方块图标会跟随当前强度变化，直观看到当前效果更轻还是更重。

#### 编辑方式

- 点击已生成的马赛克区域可以选中它。
- 拖动滑动打码路径或矩形打码区域可以移动位置。
- 矩形打码支持继续拖动边缘或角点调整大小。
- 选中滑动打码后，可以继续修改打码类型、强度值和点大小。
- 选中矩形打码后，可以继续修改打码类型和强度值。
- 按 `Delete` 可以删除选中的马赛克。

#### 使用建议

- 需要快速涂抹敏感内容时，直接使用默认滑动模式即可。
- 需要规整遮挡整块区域时，切换到矩形模式更合适。
- 遮挡文字时，通常 `8...12` 就足够；遮挡头像或较大区域时，可以继续提高到更高值。
- 如果要在同一张图里混用高斯模糊和像素马赛克，先分别设好两个类型的值，之后切换时会保留。

### 6. 文字

文字工具用于在截图上添加说明文字，适合补充短注释、标出状态或给截图加上下文。

#### 启用方式

点击工具栏中的“文字”按钮。启用后会显示文字专用选项工具栏。

#### 创建与输入

1. 点击“文字”。
2. 在截图区域内点击需要放置文字的位置。
3. 输入文字内容。
4. 按 `Return` 提交文本，或按 `Esc` 结束编辑并丢弃空白文本。

点击已有文字正文可以重新进入编辑；拖动已有文字正文可以移动文字位置。

#### 默认样式

- 默认字号：`24`。
- 可选字号：`16 / 24 / 32`。
- 默认颜色：调色板第一项红色。

#### 样式选项

文字工具支持：

- 字号：`16 / 24 / 32`。
- 颜色：调色板颜色或自定义颜色。

文字工具不显示线宽、填充、形状切换、线条类型或箭头类型。

#### 编辑方式

- 点击文字正文可以重新编辑内容。
- 拖动文字正文可以移动文字。
- 选中文字后，可以修改颜色和字号。
- 字号变化后，文本框会按新字号重新计算尺寸。
- 按 `Delete` 可以删除选中的文字。

### 7. 序号

序号工具用于给操作步骤添加编号，也可以添加对勾或叉号标记。

#### 启用方式

点击主工具栏“序号”进入标注模式。启用后会显示序号专用选项工具栏。

#### 可画内容

- 序号：彩色圆圈中显示自动递增数字。
- 对勾：独立对勾标记，没有背景圆圈。
- 叉号：独立叉号标记，没有背景圆圈。

#### 样式选项

- 类型：序号 / 对勾 / 叉号。
- 字号：`3...72`，字号会同步驱动标注整体大小。
- 颜色：调色板颜色或自定义颜色。

#### 创建与编辑

- 点击截图区域内外都可以创建标注。
- 拖动标注本体可以移动。
- 右上角蓝色叉可以删除标注。
- 右下角圆点可以缩放标注，缩放范围限制在字号 `3...72`。
- 数字标注左上角 `+` 和左下角 `-` 用于和相邻数字交换顺序。
- 删除数字标注后，剩余数字会自动连续重排。
- 对勾和叉号不参与数字排序。

## 常见问题

### 为什么标记笔不像普通画笔一样能自由画？

标记笔的定位是荧光笔高亮，当前只支持从鼠标按下到松开的直线。这样更适合给文字、表格行、代码行做整齐标注，也便于后续移动和调整方向。

### 标记笔会不会让底下文字看不清？

标记笔使用高亮混合效果，不是简单用纯色盖住截图。正常情况下，底下的深色文字仍然应该保持清晰。

### 为什么标记笔粗细按钮看起来没有实际那么粗？

按钮里的线条只是预览。为了让工具栏更美观，预览线宽会按比例缩小；实际画出来的线宽仍然是 `14 / 18 / 22`。

### 为什么标记笔改颜色后，其他工具还是红色？

标记笔有独立的默认样式。它的颜色不会影响形状、箭头线、画笔等其他工具；切回其他工具时，其他工具仍使用自己的默认颜色或之前保存的样式。

### 为什么有些工具按钮提示“功能开发中”？

工具栏中还有一部分功能尚未完成。本文只记录已经可用的功能；新工具完成后会追加到本文中。

## 文档维护规则

后续每完成一个工具栏功能，请按以下方式更新本文：

1. 在“适用范围”中把新工具加入已支持列表。
2. 在“已支持的标注工具”下面追加一个新章节。
3. 写清楚启用方式、绘制方式、默认样式、样式选项、编辑方式和快捷键。
4. 如果新工具和现有工具有明显差异，更新“工具差异速查”表格。
5. 如果用户容易疑惑，追加到“常见问题”。
6. 以当前代码行为准；如果早期设计文档与代码不一致，优先更新本文为当前实际行为。
