## About XxSnap

XxSnap is a screenshot and screen annotation app for macOS, designed to make capturing, annotating, referencing, and presenting visual information faster.

- Screenshot capture and annotation
- Scrolling capture
- Pinned images
- Text recognition
- Presentation pen and on-screen annotation

Feature availability may vary by release. Check the [official website](https://xxsnap.xxsofts.com/en/) and the latest production version for current details.
