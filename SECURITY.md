# 安全政策 / Security Policy

## 报告安全或隐私问题

请勿通过公开 Issue 报告潜在的安全漏洞、隐私问题或可能被滥用的技术细节。

请使用 GitHub 的[私密漏洞报告](https://github.com/0xkevin/xxsnap/security/advisories/new)提交报告。请尽量包含：

- 受影响的 XxSnap 版本和 macOS 版本
- 问题描述及潜在影响
- 可重复验证的步骤或最小示例
- 你已经采取的临时缓解措施

请不要在未经协调的情况下公开披露漏洞细节。

## Supported Versions

Security fixes are provided for the latest production release of XxSnap. Please confirm the issue against the latest version before reporting it when doing so is safe.

Do not report potential security vulnerabilities or privacy issues in public Issues. Use [GitHub private vulnerability reporting](https://github.com/0xkevin/xxsnap/security/advisories/new) instead.
